The ctl family

Four Rust command-line tools on one chassis. Each does one job and renders the same result as pretty text, plain text, or JSON.

forkctl

Downstream forks as audited StGit patch stacks.

$ mise run fork status

verctl

Version PRs from Changesets-format fragments. Any stack.

$ mise run ver -- prepare

ctl-core

Shared clap chassis for the *ctl CLIs. Not a command.

$ cargo add ctl-core

qctl

In-repo YAML work queues. One file, one active task.

$ mise run q -- status
